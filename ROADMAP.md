# Orbit Download Manager roadmap

Orbit continues Mister Download Manager as a Windows-only project maintained by Mithila
Prabashwara. The upstream release history is preserved in [CHANGELOG.md](CHANGELOG.md).

Current focus:

- Windows 10 and 11 builds for x64, ARM64 and x86.
- Reliable downloads, browser integration and accessible desktop controls.
- Signed Orbit releases and verified automatic updates from this repository.

Track Orbit work in [Issues](https://github.com/mthlpbs/Orbit-Download-Manager/issues).
